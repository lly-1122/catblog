关于Tomcat处理请求方式

Created2026-09-18|漏洞复刻关于Tomcat
|Post Views:

版本：

  • 9.0.0.M1 <= tomcat <= 9.0.98

  • 10.1.0-M1 <= tomcat <= 10.1.34

  • 11.0.0-M1 <= tomcat <= 11.0.2

#概述：

Tomcat在处理PUT的不完整请求的时候会产生一个临时的File会话文件存储起来，并且会将“/”转换成“.”上传到服务器上存储。

比如：

这种方式

也就是说Tomcat在处理关于有Range这种标头的请求的时候会出现这种情况。而这里的Content-Range其实表示的是他的数据有多少块，这里的分块请求是先给服务器0-2000字节的数据，剩下的4000等会给。那么这种请求服务器就会识别为未完成的请求，所以在接受的时候会在会话目录创建一个临时文件，用来存储在磁盘上。

那么这个时候我们就可以利用它来进行一个出发我们上传到服务器的恶意代码了（通过cookie）触发。
