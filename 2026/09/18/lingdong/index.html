扫描：

直接访问网站几乎看不到啥东西，用dirsearch详细扫一下目录

然后扫了之后会有一个wordpress，这个目录下还有很多目录，扫两次

wordpress目录下有很多能够访问到的目录，emm思路的话一开始也是一个一个看。这里大概内容就是这个网站是一个moziloCMS网站，emm去网上了解了一下，大概就是这个服务是用来管理网站的一个服务，可以让即便不了解网站的人也能轻松管理网站。

然后我也看了很久，后面注意到了一个文件readme.txt进去之后是一段话

大概就是说欢迎使用moziloCMS，然后跟你说一下注意事项。然后这里有个链接https://www.mozilo.de/这个链接里面有一个页面https://www.mozilo.de/Anleitung.html他对安装这个服务进行了说明，说了一个关键点是如果安装完成之后应该删除哪些文件或目录：

我前面收集信息的时候其实在网页上也有说明这个，但是在这里我才真正确认方向，install.php就是个突破口。然后因为不认识德文，一开始也不是很懂。

http://172.26.17.225/wordpress/install.php

访问这个页面之后就能够得到一个setup设置，然后这里有password可以修改“super user”的密码，这里改一下就能登录/wordpress/admin了

然后因为这是moziloCMS3.0.2的版本。网上有一个漏洞编号为CVE-2024-44871可以利用MoziloCMS 3.0 - Remote Code Execution (RCE) - PHP webapps Exploit

大概就是说，你需要先登录到admin上，之后有一个上传文件功能，可以先上传图片然后通过拦截的方式将图片的数据改为revshell命令上传，然后通过修改请求将后缀修改为php访问触发。

顺便提一下第二步的时候其实可以在dashboard页面修改后缀

revshell

触发反弹shell

然后这个靶机最扯的来了，我在这个靶机上找了很久找了suid文件找了crontab找了网站目录下的conf文件跑了一遍linpeas.sh之后，最后尝试sunset用户弱口令，sunset:sunset就上去了….

之后sudo -l查看suid权限，有一个hg命令，虽然我也不知道这个干嘛的，反正就去GTFO找吧

然后就找到了这个

通过这样就能过getrootshell

额，总的来说感觉比较草率。

不过总的来说的话，给我的经验的话就是，其实每一次渗透，一开始就可以进行爆破或者说如果一开始转了很久实在没招了可以先进行爆破，等慢慢收集足够证据找到突破点就可以一举拿下，不至于最后到头来发现原来是个弱密码….

然后后面了解了一下hg这个命令，emm，ai说是他和git有点类似，主要用于：

  • 版本控制：追踪代码或文件的历史修改记录，方便随时回滚到之前的版本。

  • 分支管理：允许开发者在不同的分支上并行开发，最后再合并。

  • 多人协作：方便团队成员之间同步代码和合并冲突。
