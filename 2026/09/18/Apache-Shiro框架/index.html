Apache Shiro框架

Created2026-09-18|漏洞复刻知识补充
|Post Views:

简介：

Apache Shiro是一个强大的安全框架，他提供了一系列的安全特性，包括认证、授权、密码学、会话管理等。Shiro可以用于各种应用程序，从简单的单体应用到复杂的分布式企业系统。

Shiro的核心组件

Shiro的框架包括几个核心的组件，他们共同协作，提供完整的安全保障。

  • Subject：主体，代表了当前正在与应用交互的用户或第三方系统。Subject可以是一个通过认证的用户，也可以是一个仅仅在于当前会话的用户。

  • SecurityManager：安全管理器，是Shiro架构的心脏，协调各个组件，提供安全性的整体保障。

  • Realm：领域，是特定于安全数据源的组件，负责从中获取应用程序的安全数据，如用户身份及权限信息。

  • Authenticator：认证器，负责主体的认证过程，这是确认主体身份的过程。

  • Authorizer：授权器，负责访问控制的过程，确定主体是否被允许进行当前的操作。

  • SessionManager：会话管理器，管理应用程序特定的会话，不依赖于底层容器的会话机制。

认证过程

在Shiro中，认证过程通常是这样的：

  1. 主体提交认证请求

  2. SecurityManager 将认证工作托给Authenticator。

  3. Authenticator通过配置的Realm来获取与提交的认证信息箱匹配的数据。

  4. 如果Realm验证成功，用户将被认为是已认证的主体，否则抛出相应的认证异常。

授权过程

授权是认证之后的一个过程，用于确定已认证的主体是否有权执行特定的操作。

  1. 主体请求访问资源。

  2. SecurityManager将授权工作托给Authorizer。

  3. Authorizer通过Realm获取主机的权限信息。

  4. 根据获取的信息，确定主体是否具有相应的权限。
