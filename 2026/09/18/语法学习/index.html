JSON（JavaScript Object Notation)

本质

一种轻量级的数据交换格式，源自JavaScript，独立于语言（几乎所有变成都支持）。

典型用途

  • Web API数据传输（前后端通信）

  • 复杂软件的配置文件（如VS Code的settings.json）

  • 存储结构化数据（如数据库导出）。

语法规则

  • 严格结构：必须用双引号””包裹键名和字符，不允许注释。

  • 数据类型：支持字符串、数字、布尔值、数组、对象、null。

INI（Initializatin File）

本质

一种传统的键值对配置文件格式，最初用于Windows系统，语法极简。

典型用途

  • 操作系统配置（如boot.ini）

  • 老旧软件的参数存储（如游戏设置）

  • 简单的项目配置（如数据库链接信息）

语法规则

  • 松散结构：键值对用=或 : 分隔，支持注释（;或#）。

  • 分节存储：用[section]划分配置区块。
